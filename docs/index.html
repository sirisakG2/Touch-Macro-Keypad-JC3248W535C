Touch Macro Keypad

Guition JC3248W535C (ESP32-S3, 3.5" 320×480 touch) running as a USB / Bluetooth macro keypad, designed from Macro Keypad Studio in the browser.

Overview

Types on your PCUSB HID keyboard when a PC has enumerated it; BLE HID keyboard otherwise.
Designed in the browserLayouts, keycap pictures, backgrounds, press motion, light effects, click sounds and macros.
Record macrosCapture real keystrokes with timing, or simplify to text and shortcuts.
Click on PC speakersThe keypad reports each press; the studio plays the chosen sound.

Build & deploy

# firmware, local (macOS)
cd firmware && pio run -t upload --upload-port $(ls /dev/cu.usbmodem* | head -1)

# studio, local
npm install && npm test && npx wrangler dev

# Cloudflare Workers Builds (set once in the dashboard)
build:  npm run build        # compiles firmware only if firmware/ changed
deploy: npm run deploy:ci

Limits

  • Text macros type with the US keyboard layout and plain ASCII only.
  • Pictures and keycap designs upload over USB only; Bluetooth saves layout and macros.
  • The click sound plays while the studio is open or installed as an app.
  • Single touch point; one key press at a time.
  • Web Serial / Web Bluetooth need Chrome or Edge on desktop.
  • No gyro/accelerometer on the board: orientation is chosen in the studio.
  • Firmware updates from the studio need USB (not Bluetooth).
