Your browser can't flash devices. Use Chrome or Edge on a computer. Open this page over https to flash.

Steps

  1. First install (new board): plug the board in with a data USB-C cable and click Install firmware. Pick the port named USB JTAG/serial debug unit.
  2. Already on firmware 1.3.0 or newer? You don't need this page: open the studio, connect over USB and click Keypad → Update firmware. The keypad installs it and restarts by itself.
  3. Updating from 1.2.0 or older (one time only): it now shows up as a keyboard, so put it in update mode first: either click Keypad → Restart into firmware update mode in the studio, or hold BOOT, tap RESET, release BOOT. Then click Install firmware.
  4. When it finishes, press RESET (or unplug and plug in again). Moving to 1.3.0 clears the keypad's storage once, so open the studio and click Save to keypad again - your design is still in the browser.
  5. Choosing Erase also wipes your saved layout and pictures. Export your project in the studio first.
