Steps

  1. Keypad already on firmware 1.3.0 or newer: you don't need this page. In the studio, connect over USB and click Keypad → Update firmware. It installs and restarts by itself.
  2. Keypad on 1.2.0 or older (one time): in the studio, connect over USB and click Keypad → Update to 1.3.0 (one-time setup). The keypad switches itself into update mode and this page opens. Click Install firmware and pick USB JTAG/serial debug unit. Afterwards click Save to keypad in the studio once, because this step clears the keypad's storage.
  3. New board: plug it in with a data USB-C cable, click Install firmware and pick USB JTAG/serial debug unit.
  4. Last resort (the keypad doesn't respond): unplug it, hold BOOT, plug it in, release BOOT, then install. Press RESET afterwards if the screen stays dark.
  5. Choosing Erase also wipes your saved layout and pictures. Export your project in the studio first.
