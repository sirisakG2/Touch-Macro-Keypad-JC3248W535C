Touch Macro Keypad

คีย์แพดมาโครจอสัมผัส 3.5 นิ้ว สร้างจากบอร์ด Guition JC3248W535C ออกแบบทุกอย่างได้จากเว็บเบราว์เซอร์

เปิด Macro Keypad Studioติดตั้งเฟิร์มแวร์ซอร์สโค้ดบน GitHub

1. คืออะไร

พิมพ์เข้าคอมพิวเตอร์ได้ทำงานเป็นคีย์บอร์ด USB เมื่อเสียบกับ PC หรือ Mac และเป็นคีย์บอร์ดบลูทูธเมื่อใช้ไฟจากที่ชาร์จหรือแบตเตอรี่
ออกแบบในเบราว์เซอร์หน้า ปุ่ม ไอคอน รูปภาพ พื้นหลัง เอฟเฟกต์ และมาโคร ทำได้ทั้งหมดใน Macro Keypad Studio
อัปเดตได้ในคลิกเดียวเฟิร์มแวร์ใหม่ติดตั้งผ่าน USB จากสตูดิโอ แล้วคีย์แพดจะรีสตาร์ตเอง
เสียงคลิกบนคอมพิวเตอร์สตูดิโอจะเล่นเสียงคลิกผ่านลำโพงทุกครั้งที่แตะปุ่มบนคีย์แพด

สิ่งที่ต้องมี

  • บอร์ด Guition JC3248W535C (ESP32-S3 จอสัมผัส 3.5 นิ้ว 320×480)
  • สาย USB-C แบบรับส่งข้อมูลได้ (สายที่ชาร์จได้อย่างเดียวใช้ไม่ได้)
  • Chrome หรือ Edge บนคอมพิวเตอร์ (Windows, macOS, Linux, ChromeOS) เบราว์เซอร์อื่นยังสื่อสารกับอุปกรณ์ USB/บลูทูธไม่ได้

2. ติดตั้งครั้งแรก

  1. เสียบบอร์ดเข้ากับคอมพิวเตอร์
  2. เปิดหน้า Firmware แล้วกด Install firmware
  3. เลือกพอร์ตชื่อ USB JTAG/serial debug unit แล้วยืนยัน การติดตั้งใช้เวลาประมาณ 1 นาที
  4. เมื่อเสร็จ คีย์แพดจะรีสตาร์ตและแสดง Macro Keypad v… ตามด้วยเลย์เอาต์เริ่มต้น
ขึ้นว่า "Failed to initialize"? แปลว่าบอร์ดยังไม่อยู่ในโหมดติดตั้ง ให้ถอดสาย แล้วกดปุ่ม BOOT ค้างไว้ (หนึ่งในปุ่มเล็ก ๆ สองปุ่มในรูด้านหลังบอร์ด) เสียบสายกลับ ปล่อยปุ่ม BOOT แล้วลองใหม่ ในโหมดนี้จอจะดับ ถือว่าปกติ ติดตั้งเสร็จแล้วกด RESET (หรือถอดเสียบสายใหม่)

หลังติดตั้งครั้งแรกแล้ว ไม่ต้องใช้ปุ่ม BOOT อีกเลย ดูหัวข้ออัปเดตเฟิร์มแวร์

3. การเชื่อมต่อ

ใช้เป็นคีย์บอร์ด

  • USB: เสียบเข้ากับคอมพิวเตอร์ ใช้พิมพ์ได้ทันที แถบด้านบนของคีย์แพดจะแสดง USB
  • บลูทูธ: ใช้ไฟจากที่ชาร์จหรือแบตเตอรี่ ระหว่างรอจับคู่แถบด้านบนจะแสดง BLE… ให้จับคู่อุปกรณ์ชื่อ Macro Keypad ในการตั้งค่าบลูทูธของคอมพิวเตอร์เหมือนคีย์บอร์ดทั่วไป เมื่อเชื่อมต่อแล้วจะแสดง BLE
  • --- แปลว่ายังไม่ได้เชื่อมต่อกับอะไรเลย แตะปุ่มแล้วจะยังพิมพ์ไม่ได้

เชื่อมต่อกับสตูดิโอ

  1. เปิดสตูดิโอใน Chrome/Edge
  2. กด USB (แนะนำ) หรือ Bluetooth ที่ด้านบน แล้วเลือกคีย์แพด
  3. ป้ายสถานะจะเปลี่ยนเป็นสีเขียว เช่น USB · fw 1.4.0

ผ่านบลูทูธบันทึกเลย์เอาต์และมาโครได้ แต่รูปภาพ ดีไซน์ปุ่ม และการอัปเดตเฟิร์มแวร์ต้องใช้ USB

4. ออกแบบปุ่ม

คลิกปุ่มบนหน้าจอจำลองในสตูดิโอเพื่อเลือก ลากเพื่อย้ายตำแหน่ง ลากมุมสีขาวเพื่อปรับขนาด โหมด Try it (เหนือหน้าจอ) ใช้แตะลองดูเอฟเฟกต์และเสียงได้

หน้าและการจัดวาง

  • Pages (แผงซ้าย): เพิ่ม ทำสำเนา เรียงลำดับ และตั้งชื่อหน้า ถ้ามีมากกว่าหนึ่งหน้า คีย์แพดจะมีแถบ < > ด้านล่างไว้เปลี่ยนหน้า
  • Layout grid: กำหนดจำนวนแถว คอลัมน์ ระยะขอบ และช่องว่าง แล้วกด Arrange keys in grid
  • Background: ใช้สีเดียว ไล่เฉดสี หรือรูปภาพ (ปรับการจัดวางและความมืดได้)
  • Screen orientation (แท็บ Keypad): แนวตั้ง แนวนอน (หมุนคีย์แพดไปทางซ้ายหรือขวา) หรือกลับหัว บอร์ดนี้ไม่มีเซนเซอร์วัดการเอียง จึงต้องเลือกเองตรงนี้

แท็บ Keycap

  • Label (ข้อความบนปุ่ม): พิมพ์ได้ทุกภาษารวมถึงภาษาไทยและอีโมจิ ปรับฟอนต์ ขนาด ความหนา สี ตำแหน่ง และความโปร่งใสของข้อความ (0% ทึบ ถึง 100% มองไม่เห็น)
  • Icon: กด Choose icon… เพื่อเปิดตารางไอคอนฟรีกว่า 1,800 แบบที่ค้นหาได้ (ค้นด้วยคำภาษาอังกฤษ เช่น "copy", "volume", "mail") เลือกสี ขนาด และตำแหน่ง: เหนือข้อความ ซ้ายของข้อความ หรือไอคอนอย่างเดียว
  • Keycap style: แบบเรียบ 3D แก้ว เส้นขอบ นีออน หรือรูปภาพ พร้อมสีและความมนของมุม
  • Picture: กด Choose picture… หรือลากรูปไปวางบนปุ่มในหน้าจอจำลองได้เลย เลือกการจัดวาง: เต็มปุ่ม พอดีในปุ่ม หรือไอคอนเล็กเหนือข้อความ
  • Picture across keys (แผงซ้าย): ใช้รูปเดียวกระจายทั่วทุกปุ่มในหน้า แต่ละปุ่มจะแสดงส่วนของรูปตามตำแหน่ง ปุ่มที่มีรูปของตัวเองจะใช้รูปของตัวเองแทน
  • Apply … to This page / All pages: คัดลอกสไตล์ข้อความและไอคอน หรือสไตล์ปุ่มและการจัดวางรูป จากปุ่มที่เลือกไปยังปุ่มอื่นทั้งหน้าหรือทุกหน้า

5. คำสั่งและมาโคร

แท็บ Action แสดงสิ่งที่ปุ่มจะพิมพ์ เรียงจากบนลงล่าง:

  • + Shortcut คีย์ลัด: ติ๊กปุ่มปรับ (Ctrl, Shift, Alt, Win/Cmd) แล้วเลือกปุ่ม วิธีที่ง่ายที่สุดคือกด Press keys… แล้วกดคีย์ลัดจริงบนคีย์บอร์ด
  • + Text พิมพ์ข้อความ
  • + Pause หยุดรอ (สูงสุด 10 วินาที)
  • ● Record keys อัดการกดคีย์บอร์ดจริง แล้วกด Stop ระบบจะจัดให้เป็นข้อความและคีย์ลัด หรือติ๊ก Keep exact timing เพื่อเล่นซ้ำตามจังหวะจริงทุกอย่าง
  • ลากที่ ⋮⋮ หรือกด ↑ ↓ เพื่อเรียงลำดับ และกด Run on keypad เพื่อทดลอง
ผู้ใช้ Mac ให้ใช้ Win/Cmd แทน Ctrl เช่น Copy = Cmd+C, Paste = Cmd+V (ปุ่มตัวอย่างที่ติดมาใช้ Ctrl แบบ Windows)
คำสั่ง Text พิมพ์ด้วยผังแป้นพิมพ์ภาษาอังกฤษ (US) และตัวอักษรพื้นฐานเท่านั้น (A–Z ตัวเลข และเครื่องหมาย) จึงยังพิมพ์ข้อความภาษาไทยด้วยคำสั่ง Text ไม่ได้ ส่วนข้อความบนปุ่มใช้ภาษาไทยได้ตามปกติ

6. แอนิเมชัน แสง และเสียง

  • Press motion: ยุบ (push) เด้งออก (pop) จม (sink) เด้งดึ๋ง (bounce) หรือไม่มี
  • Light: เรืองแสง (glow) วงกระเพื่อม (ripple) แฟลช (flash) หรือเส้นขอบ (outline) ปรับสีและความเร็วได้ ปุ่ม Apply … to whole page ใช้คัดลอกไปทั้งหน้า
  • Idle ambient light (แท็บ Keypad): breathe (หายใจ) rainbow (สายรุ้ง) หรือ wave (คลื่น) เมื่อไม่ได้แตะจอสักพัก
  • ความสว่างและการหรี่จอ (แท็บ Keypad): จอจะหรี่ลงหลังไม่ได้ใช้งานสักพัก การแตะครั้งแรกจะแค่ปลุกจอ
  • Click sound on PC (แท็บ Keypad): เลือกเสียงหรืออัปโหลดเสียงของตัวเอง เสียงจะดังเมื่อเปิดสตูดิโอไว้ (หรือติดตั้งเป็นแอปจากแถบที่อยู่) และเชื่อมต่ออยู่

7. Save to keypad กับ Update firmware ต่างกันอย่างไร

Save to keypadUpdate firmware
ส่งอะไรงานออกแบบของคุณ: หน้า ปุ่ม รูป ไอคอน เอฟเฟกต์ มาโครโปรแกรมของคีย์แพด
ใช้เมื่อไรหลังแก้ไขงานออกแบบทุกครั้งเฉพาะเมื่อมีเวอร์ชันใหม่
คีย์แพดรีสตาร์ตไหมไม่ จะขึ้นคำว่า "Saved"ใช่ รีสตาร์ตเอง
เลย์เอาต์เปลี่ยนไหมเปลี่ยนไม่เปลี่ยน เก็บไว้เหมือนเดิม

ปุ่ม Save to keypad จะมีจุดสีส้มเมื่อคีย์แพดยังไม่มีงานออกแบบล่าสุด และแสดง Saved ✓ เมื่อตรงกันแล้ว

8. อัปเดตเฟิร์มแวร์

  1. เชื่อมต่อสตูดิโอผ่าน USB
  2. เปิดแท็บ Keypad → Firmware จะแสดงเวอร์ชันที่ติดตั้งอยู่และเวอร์ชันล่าสุด
  3. กด Update to x.y.z คีย์แพดจะแสดง "Updating n %" แล้วรีสตาร์ตเอง สตูดิโอจะเชื่อมต่อกลับให้อัตโนมัติ ไม่ต้องกดปุ่มบนบอร์ด และเลย์เอาต์ยังอยู่ครบ

คีย์แพดที่เวอร์ชันต่ำกว่า 1.3.0 จะขึ้นปุ่ม Update … (one-time setup): คีย์แพดจะเข้าโหมดติดตั้งเองและเปิดหน้า Firmware ให้ กด Install แล้วเลือก USB JTAG/serial debug unit จากนั้นกด Save to keypad อีกหนึ่งครั้ง (ขั้นตอนครั้งเดียวนี้จะล้างหน่วยความจำของคีย์แพด แต่งานออกแบบยังอยู่ในเบราว์เซอร์)

ดูเวอร์ชันของคีย์แพดได้จาก: ตัวเลขสีเทาเล็ก ๆ ในแถบด้านบน หน้าจอตอนเปิดเครื่อง หรือแตะแถบด้านบนค้างไว้ 1.5 วินาที

9. แก้ปัญหา

แตะปุ่มแล้วไม่มีอะไรเกิดขึ้น
  • ดูแถบด้านบนของคีย์แพด ถ้าเป็น --- แปลว่ายังไม่เชื่อมต่อ ให้เสียบ USB หรือจับคู่บลูทูธ
  • ในแท็บ Keypad ของสตูดิโอ Typing via ควรเป็น USB หรือ BLE ถ้าเป็น NONE ในเวอร์ชันเก่า ให้อัปเดตเฟิร์มแวร์
  • บน Mac คีย์ลัด Ctrl ใช้ไม่ได้ในแอปส่วนใหญ่ ให้เปลี่ยนเป็น Win/Cmd
  • ถ้าจอหรี่อยู่ การแตะครั้งแรกจะแค่ปลุกจอ
ไม่มีเสียงคลิกต้องเปิดสตูดิโอไว้และเชื่อมต่ออยู่ ติ๊ก Play a click… (แท็บ Keypad) เปิดเสียง และปุ่มนั้นไม่ได้ตั้งเป็น "No sound" ให้คลิกที่ใดก็ได้ในสตูดิโอหนึ่งครั้ง เพราะเบราว์เซอร์อนุญาตให้เล่นเสียงหลังผู้ใช้คลิกเท่านั้น
ขึ้นว่า "Save failed: crc mismatch"แก้แล้วในสตูดิโอ build 6515159 และเฟิร์มแวร์ 1.3.2 ให้รีโหลดสตูดิโอ (Cmd/Ctrl+Shift+R) แล้วอัปเดตเฟิร์มแวร์
หน้า Firmware ขึ้น "Failed to initialize" หรือค้างที่ "wrapping up"ให้ใช้ปุ่ม Update firmware ในสตูดิโอแทน ถ้าจำเป็นต้องใช้หน้า Firmware: กดปุ่ม BOOT ค้างไว้ระหว่างเสียบสาย แล้วเลือก USB JTAG/serial debug unit ถ้าค้างที่ "wrapping up" หลัง 100% ให้ปิดหน้าต่างนั้นแล้วกด RESET
หน้าสตูดิโอค้าง ("Page Unresponsive")แก้แล้วในสตูดิโอ build 85d9c74 ให้รีโหลดด้วย Cmd/Ctrl+Shift+R
รูปภาพไม่ขึ้นบนคีย์แพดรูปภาพและดีไซน์ปุ่มส่งได้ผ่าน USB เท่านั้น ให้เชื่อมต่อผ่าน USB แล้วกด Save อีกครั้ง
แนวนอนแสดงกลับหัวเลือกแนวนอนอีกแบบในแท็บ Keypad แล้วกด Save
เริ่มใหม่ทั้งหมดกด Export เก็บงานออกแบบไว้ก่อน จากนั้นใช้ Load from keypad / Import หรือใช้หน้า Firmware แบบ Erase เพื่อล้างคีย์แพดทั้งหมด
